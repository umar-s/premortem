# Pool of perspectives (углы зрения)

Скилл выбирает 6 углов под тип плана: 4 критичных + 1 ситуативный + «Будущий поддерживающий» (sacred — для WYSIATI-микрошага).

## Base (почти всегда)

- **Клиент / пользователь** — что думает тот для кого делается.
- **Исполнитель / команда** — чего не хватит у тех кто делает.
- **Противник или альтернатива** — кто/что перебьёт; на что юзер уйдёт вместо.
- **Допущения и доказательства** — что считаем правдой без проверки.
- **Будущий поддерживающий** — как это будет жить через год без активного внимания. *(Включает WYSIATI-микрошаг: «кого/что мы НЕ видим?»)*

## Ситуативные

| Тип плана | Углы |
|---|---|
| Продукт / запуск | Конкурент, Ценообразование |
| Технический проект | Архитектура, Эксплуатация |
| Стратегический поворот | Рынок, Тайминг |
| Личное решение | Будущий-ты-через-N-лет |
| Найм | Культура команды, Runway |
| Ценовое изменение | Существующие клиенты, Churn |

## Профили (для switch-классификатора)

Скрипт `classify_angles.py` определяет профиль по ключевым словам в описании плана. Каждый профиль = 4 критичных + 1 ситуативный из таблицы + «Будущий поддерживающий» = 6 углов на 3 помощника = (2,2,2).

| Профиль | Триггеры (regex/keyword) | Ситуативные углы |
|---|---|---|
| `product_launch` | launch, запуск, релиз, GA, beta | Конкурент, Ценообразование |
| `pricing_change` | price, pricing, цена, тариф | Существующие клиенты, Churn |
| `hire` | hire, найм, вакансия, candidate | Культура команды, Runway |
| `tech_project` | refactor, migration, миграция, архитектур | Архитектура, Эксплуатация |
| `strategic_pivot` | pivot, поворот, новое направление, market shift | Рынок, Тайминг |
| `personal_decision` | should I, стоит ли мне, личн | Будущий-ты-через-N-лет |
| `default` | (fallback) | Конкурент, Тайминг |
